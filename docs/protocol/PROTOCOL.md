# MetalMonitor 通信协议 v0.9

> 本文档是 STM32 固件与 WPF 上位机之间的通信契约。两端必须严格遵守，任何字段边界、字节序、CRC 范围的歧义以本文档为准。
>
> 版本：v0.9（草案，待 W7 冻结为 v1.0）
> 最后更新：2026-10-06

## 1. 物理层

- 接口：USART1（PA9 TX / PA10 RX）
- 波特率：115200
- 数据位：8，停止位：1，校验：无
- 传输方向：当前仅上行（固件→上位机），下行命令待 T5.x 扩展

## 2. 帧总览

每帧固定 11 字节，结构如下：

```
偏移  长度  字段      说明
 0     2    AA 55     帧头（同步标记，固定值）
 2     1    LEN       载荷长度（CMD + 数据字段，不含帧头与 CRC）
 3     1    CMD       命令码
 4     n    PAYLOAD   数据载荷（长度 = LEN - 1）
4+n    2    CRC16     校验（低字节在前）
```

**当前 CMD=0x01 的帧总长 = 11 字节**（帧头 2 + LEN 1 + CMD 1 + 载荷 5 + CRC 2）。

## 3. 字节序约定

**全帧所有多字节字段均为小端（低字节在前，Little-Endian）。**

- 温度 int16：低字节先发，高字节后发
- mV uint16：低字节先发，高字节后发
- CRC16：低字节先发，高字节后发

## 4. CMD 表

| CMD | 方向 | 名称 | 载荷 |
|---|---|---|---|
| 0x01 | 上行 | 传感器数据帧 | 温度(2) + mV(2) + 状态(1) = 5 字节 |

> 下行命令（CMD 0x02~）待 T5.x 定义。

## 5. CMD 0x01 上行数据帧详解

```
偏移  长度  字段       类型      说明
 0     2    帧头       -         固定 AA 55
 2     1    LEN        uint8     = 6（CMD + 载荷 = 1 + 5）
 3     1    CMD        uint8     = 0x01
 4     2    温度       int16     实际温度 × 10，小端
 6     2    电压       uint16    PA6 ADC 换算的毫伏值，小端
 8     1    状态       uint8     bit0: DS18B20 在线(1)/离线(0)；其余位保留
 9     2    CRC16      uint16    校验值，小端
```

### 5.1 温度编码

- 原始值 = 实际温度（℃）× 10，四舍五入取整
- 例：25.3℃ → 253 → 0x00FD → 帧内 `FD 00`
- 范围：int16，-3276.8℃ ~ +3276.7℃（实际 DS18B20 量程 -55~125℃）

### 5.2 电压编码

- 原始值 = ADC 原始值 × 3300 / 4095，取整（单位 mV）
- 例：3.298V → 3298 → 0x0CE2 → 帧内 `E2 0C`
- 范围：uint16，0 ~ 3300 mV

### 5.3 状态位

| bit | 含义 |
|---|---|
| 0 | DS18B20 在线：1=存在脉冲正常，0=离线/读失败 |
| 1~7 | 保留，当前为 0 |

## 6. CRC16 规则

- 算法：CRC-16/MODBUS
- 多项式：0x8005（反射形式 0xA001）
- 初值：0xFFFF
- 反射：输入输出均反射（refin=true, refout=true）
- 异或输出：0x0000
- **覆盖范围：从 LEN（偏移 2）开始，到状态位（偏移 8）结束，共 7 字节**（不含帧头 AA 55，不含 CRC 自身）
- 帧内放置：小端，低字节在前

### 6.1 标准测试向量

- 输入：ASCII 字符串 `"123456789"`（9 字节）
- 期望输出：`0x4B37`
- 固件与上位机两端均须通过此向量

## 7. 完整帧示例

### 示例帧（hex）

```
AA 55 06 01 FD 00 E2 0C 01 75 F3
```

### 逐字段解析

| 偏移 | 字节 | 字段 | 值 | 解析 |
|---|---|---|---|---|
| 0-1 | AA 55 | 帧头 | - | 同步 |
| 2 | 06 | LEN | 6 | CMD + 5 字节载荷 |
| 3 | 01 | CMD | 0x01 | 上行数据帧 |
| 4-5 | FD 00 | 温度 | 0x00FD = 253 | 25.3℃ |
| 6-7 | E2 0C | 电压 | 0x0CE2 = 3298 | 3.298V |
| 8 | 01 | 状态 | 0x01 | DS18B20 在线 |
| 9-10 | 75 F3 | CRC | 0xF375 | 校验通过 |

### CRC 验证

- 计算输入：`06 01 FD 00 E2 0C 01`（偏移 2~8，共 7 字节）
- 期望输出：`0xF375`
- 帧内存储：`75 F3`（低字节在前）

## 8. 上报节奏

- 周期：1 Hz（每秒 1 帧）
- 由固件 SysTick 定时器触发，非阻塞调度
- 上位机应容忍 ±50ms 抖动
