# MetalMonitor 通信协议 v0.9

> 本文档是 STM32 固件与 WPF 上位机之间的通信契约。两端必须严格遵守，任何字段边界、字节序、CRC 范围的歧义以本文档为准。
>
> 版本：v0.9（草案，W5 T5.4 冻结为 v1.0）
> 最后更新：2026-10-14

## 1. 物理层

- 接口：USART1（PA9 TX / PA10 RX）
- 波特率：115200
- 数据位：8，停止位：1，校验：无
- 传输方向：当前仅上行（固件→上位机），下行命令待 T5.x 扩展

## 2. 帧总览

每帧固定 12 字节，结构如下：

```
偏移  长度  字段      说明
 0     2    AA 55     帧头（同步标记，固定值）
 2     1    NODE_ID   节点地址（0x00=单节点/未分配；0x01~0xFE 多节点地址；0xFF 保留）
 3     1    LEN       载荷长度（CMD + 数据字段，不含帧头、NODE_ID 与 CRC）
 4     1    CMD       命令码
 5     n    PAYLOAD   数据载荷（长度 = LEN - 1）
5+n    2    CRC16     校验（低字节在前）
```

**当前 CMD=0x01 的帧总长 = 12 字节**（帧头 2 + NODE_ID 1 + LEN 1 + CMD 1 + 载荷 5 + CRC 2）。帧总长公式：**LEN + 6**。

**最大帧长约束：单帧总长 ≤ 32 字节（即 LEN ≤ 26）**。固件端发送的任何帧都不得超过此限；上位机解析器将 LEN > 26 或 LEN = 0 的帧判为非法并丢弃。此约束与上位机帧组装缓冲（`FrameBufferSize = 32`）一一对应，协议扩展新 CMD 时两端须同步检查载荷预算。

### 2.1 NODE_ID 路由约定（2026-10-14 新增）

NODE_ID 是**帧格式的固定部分**：任何 v0.9 修订版之后的帧都必须携带，固件固定发送、上位机固定按偏移 2 解析——**不存在"按配置切换解析方式"的模式**（同一字节流两种解析法会导致错位吞帧）。

- `0x00`：单节点/未分配地址（当前唯一在用值，固件 `#define DEVICE_NODE_ID 0`）。
- `0x01~0xFE`：多节点地址，上位机按启动时加载的**路由表**（config.json → Serial:NodeRouting，只读快照，运行期不可变）映射到设备；收到路由表外地址的帧时不崩溃、不错误路由，计入 UnknownNodeCount 并写日志。
- `0xFF`：保留（未来广播语义，当前禁止使用）。
- 单节点与多节点是同一份解析代码、同一种帧格式，区别仅为路由表 1 行还是 N 行（同 Modbus 主站轮询表范式）。

## 3. 字节序约定

**全帧所有多字节字段均为小端（低字节在前，Little-Endian）。**

- 温度 int16：低字节先发，高字节后发
- mV uint16：低字节先发，高字节后发
- CRC16：低字节先发，高字节后发

## 4. CMD 表

| CMD | 方向 | 名称 | 载荷 |
|---|---|---|---|
| 0x01 | 上行 | 传感器数据帧 | 温度(2) + mV(2) + 状态(1) = 5 字节 |

> 下行命令（CMD 0x02~）待 T5.x 定义。

## 5. CMD 0x01 上行数据帧详解

```
偏移  长度  字段       类型      说明
 0     2    帧头       -         固定 AA 55
 2     1    NODE_ID    uint8     节点地址，当前固定 0x00（见 §2.1）
 3     1    LEN        uint8     = 6（CMD + 载荷 = 1 + 5）
 4     1    CMD        uint8     = 0x01
 5     2    温度       int16     实际温度 × 10，小端
 7     2    电压       uint16    PA6 ADC 换算的毫伏值，小端
 9     1    状态       uint8     bit0: DS18B20 在线(1)/离线(0)；其余位保留
10     2    CRC16      uint16    校验值，小端
```

### 5.1 温度编码

- 原始值 = 实际温度（℃）× 10，四舍五入取整
- 例：25.3℃ → 253 → 0x00FD → 帧内 `FD 00`
- 范围：int16，-3276.8℃ ~ +3276.7℃（实际 DS18B20 量程 -55~125℃）

### 5.2 电压编码

- 原始值 = ADC 原始值 × 3300 / 4095，取整（单位 mV）
- 例：3.298V → 3298 → 0x0CE2 → 帧内 `E2 0C`
- 范围：uint16，0 ~ 3300 mV

### 5.3 状态位

| bit | 含义 |
|---|---|
| 0 | DS18B20 在线：1=存在脉冲正常，0=离线/读失败 |
| 1~7 | 保留，当前为 0 |

## 6. CRC16 规则

- 算法：CRC-16/MODBUS
- 多项式：0x8005（反射形式 0xA001）
- 初值：0xFFFF
- 反射：输入输出均反射（refin=true, refout=true）
- 异或输出：0x0000
- **覆盖范围：从 NODE_ID（偏移 2）开始，到状态位（偏移 9）结束，共 8 字节**（不含帧头 AA 55，不含 CRC 自身）。NODE_ID 纳入 CRC 是为了让地址位被干扰翻转时校验失败，避免数据被错误路由到其他节点。
- 帧内放置：小端，低字节在前

### 6.1 标准测试向量

- 输入：ASCII 字符串 `"123456789"`（9 字节）
- 期望输出：`0x4B37`
- 固件与上位机两端均须通过此向量

## 7. 完整帧示例

### 示例帧（hex）

```
AA 55 00 06 01 FD 00 E2 0C 01 2E F8
```

### 逐字段解析

| 偏移 | 字节 | 字段 | 值 | 解析 |
|---|---|---|---|---|
| 0-1 | AA 55 | 帧头 | - | 同步 |
| 2 | 00 | NODE_ID | 0x00 | 单节点/未分配 |
| 3 | 06 | LEN | 6 | CMD + 5 字节载荷 |
| 4 | 01 | CMD | 0x01 | 上行数据帧 |
| 5-6 | FD 00 | 温度 | 0x00FD = 253 | 25.3℃ |
| 7-8 | E2 0C | 电压 | 0x0CE2 = 3298 | 3.298V |
| 9 | 01 | 状态 | 0x01 | DS18B20 在线 |
| 10-11 | 2E F8 | CRC | 0xF82E | 校验通过 |

### CRC 验证

- 计算输入：`00 06 01 FD 00 E2 0C 01`（偏移 2~9，共 8 字节）
- 期望输出：`0xF82E`
- 帧内存储：`2E F8`（低字节在前）

## 8. 上报节奏

- 周期：1 Hz（每秒 1 帧）
- 由固件 SysTick 定时器触发，非阻塞调度
- 上位机应容忍 ±50ms 抖动
