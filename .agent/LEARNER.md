# LEARNER

## 已掌握
- DI 容器构造函数选择规则（贪心选参数最多且可解析的 public 构造函数；internal 不参与）
- readonly 字段只能在构造函数体内赋值（CS0191）
- 能力维度（IsAvailable）与状态维度（IsConnected）的区分

## 正在建立
- 多文件项目的架构直觉（能识别构造函数族是"约定"而非"契约"）
- 对静默行为的敏感度（主动要求全部显式化）

## 易混淆点
- "可空参数本身有问题"❌ → 正确理解：可空参数只在暴露给 DI 的 public 构造函数上有害，internal 测试构造函数可用（用户本人澄清）
